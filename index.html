📖 대필 편집기 사용방법

스나 제작 · 사진 준비부터 저장과 전시까지 한곳에서 안내

처음 시작할 때 회원가입 후 관리자 승인이 완료되면 사용할 수 있어요. 사진은 가급적 게임의 원본 스크린샷을 사용하세요. 이미 한 번 잘린 사진은 빠진 장식을 완전히 복구하지 못할 수 있어요.

1. 👕 옷 사진 추출

  1. 옷 추출을 선택하고 게임 스크린샷을 추가하세요.
  2. 사진에서 자를 옷 카드를 터치해 선택하세요. 여러 장도 선택할 수 있어요.
  3. 선택한 옷 자르기를 누르고 결과를 확인하세요.
  4. 개별 저장 또는 모두 저장으로 필요한 사진을 저장하세요.

2. ✂ 총기·차량 카드 자르기

  1. 총 자르기에서 총기 또는 차량 카드가 표시된 게임 스크린샷을 불러오세요.
  2. 총기·차량 카드를 선택하고 선택한 카드 자르기를 누르세요.
  3. 누락되거나 잘못 선택한 카드는 확인 후 다시 선택하세요.
  4. 개별 저장 또는 모두 저장을 사용하세요.

3. 🎯 킬로그 커팅과 장식 보정

  1. 킬로그 커팅에서 일반/고번 모드를 고르고 자르기 전 원본 스크린샷을 추가하세요.
  2. 사진 속 ‘킬 알림’ 막대나 장식을 터치하세요. 작으면 사진 확대(＋) 후 눌러보세요.
  3. 자동 인식된 결과를 미리보기로 확인하고, 장식이 잘리면 결과 카드의 정밀 보정을 눌러 살리기·지우기 표시 후 정밀 재분리하세요.
  4. 보정 적용 후 가운데 정렬된 PNG를 미리보기로 확인하고 저장하세요.

왼쪽·오른쪽·위쪽·아래쪽 슬라이더와 복원·지우기 브러시로 누락된 장식을 복원하거나 배경을 정리하세요. 이미 제거된 장식은 잘린 PNG만으로 되살릴 수 없으므로 원본 스크린샷을 다시 불러와야 해요.

4. 🖼️ 이미지 합치기

  1. 합치기에서 여러 사진을 추가하세요.
  2. 배치와 순서를 확인하고 위치 옵션을 선택하세요.
  3. 미리보기에 문제가 없는지 확인한 뒤 JPG 이미지 저장을 누르세요.

5. 📝 대필판 만들기

  1. 대필판에서 옷 사진과 총기·차량 사진을 각각 추가하세요.
  2. 저스펙·중스펙·고스펙 판을 선택하고 사진 순서와 배치를 확인하세요.
  3. 문의 문구, 보조 문구, 대필 이름, 옷·총 이름과 레벨을 입력하세요.
  4. 필요하면 글자 크기·위치·색상·그림자를 조절하고 미리보기를 확인하세요.
  5. PNG 저장을 누르면 대필판 결과를 저장할 수 있어요.

6. 🏛️ 전시관과 작품 관리

  1. 대필판 PNG 저장 시 작품이 전시관에 자동 등록·공개될 수 있어요. 저장 전 공개될 내용과 사진을 확인하세요.
  2. 전시관에서 전체 공개 작품을 확인하거나 내 작품을 선택하세요.
  3. 필요하면 본인이 등록한 작품을 찾아 삭제할 수 있어요. 이용 권한·기간에 따라 접근이 제한될 수 있어요.

7. 📥 저장과 문제 해결

  • 기기에 공유·저장 창이 뜨면 사진 또는 파일 앱에 저장할 곳을 선택하세요. 브라우저에 따라 다운로드 방식이 달라질 수 있어요.
  • 사진이 인식되지 않으면 잘린 결과가 아니라 원본 스크린샷을 사용하고, 해당 기능과 일반/고번 모드를 다시 확인하세요.
  • 장식이 잘렸거나 검은 잔배경이 남으면 보정 기능을 사용하고 저장 전에 PNG를 확대해서 확인하세요.
  • 프로그램 변경 사항은 ℹ 제작자 → 업데이트 내역에서 확인할 수 있어요.

8. 💾 새 기능: 작업 저장·프리셋·일괄 추출

  1. 작업 이어하기: 대필판의 '현재 작업 임시 저장' 또는 킬로그 사진함의 '지금 저장'을 누르세요. 자동 저장도 작동하며, 다시 접속할 때 '이전 작업 이어하기'로 원본과 설정을 불러올 수 있어요. 이 기기의 브라우저 데이터를 삭제하면 사라질 수 있어요.
  2. 실행 취소·다시 실행: 킬로그의 '자동 추출' 창에서 이전 작업을 확인하세요.
  3. 개인별 설정: 대필판 아래에 설정 이름을 쓰고 '내 설정 추가'를 누른 뒤, 목록에서 불러오거나 삭제하세요. Firebase 규칙이 없으면 기기 내부에만 임시 저장돼요.
  4. 일괄 추출: 옷·총은 '사진함 자동 추출', 킬로그는 '현재 사진함 일괄 추출'을 누르세요. 인식 실패 사진은 직접 확인하세요.
  5. 오류 신고: 로그인 후 화면 오른쪽 아래의 '오류 신고'를 누르세요. 사진 첨부는 선택사항이며 동의한 경우에만 전송합니다.
